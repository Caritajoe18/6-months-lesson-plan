# JavaScript Fundamentals: Project Ideas

Choose a project and build a program that solves the problem. Your project should use at least three of the JavaScript concepts we have studied: **variables, objects, arrays, loops, and conditionals**.

For each project, decide what information your program needs, how it will process that information, and what result it will show the user.

## 0. Odd-or-Even and Letter Helper

Build a learning game that helps children tell whether a number is even or odd and whether a letter is a vowel or consonant. The program should check the kind of input it receives and display the correct category. It should also handle an input that is not a single letter or number.

**Your program should use:** a function with an argument and return value, conditionals, and variables. You could also use a loop to let the player try again and an object to keep track of scores.

## 1. Classroom Quiz Game

Build a quiz that asks students questions and tells them whether each answer is correct. At the end, show the student's total score and a message based on how well they did.

**Your program should use:** an array of question objects, a loop to go through the questions, and conditionals to check answers and choose a final message.

## 2. Mini Shop and Shopping Basket

Build a small shop program where a customer can view products, add items to a basket, and see the total cost. The program should tell the customer if an item is out of stock or if their basket is empty.

**Your program should use:** product objects, arrays for products and basket items, loops to calculate or display information, and conditionals for stock and basket checks.

## 3. Pocket-Money Budget Helper

Build a program that helps a student plan how to spend their pocket money. Let the student enter their budget and a list of planned purchases. Show the total cost and how much money will be left, or explain that they have gone over budget.

**Your program should use:** variables for the budget and totals, an array of purchase objects, a loop to add costs, and conditionals to compare spending with the budget.

## 4. Class Attendance Checker

Build a program that records whether each student is present or absent. At the end, show the number of students present and absent, and list the names of any students who are absent.

**Your program should use:** an array of student objects, a loop to check each student's attendance, and conditionals to count and list students.

## 5. Book Borrowing Tracker

Build a simple library program that keeps a list of books and whether each one is available or borrowed. Let a user search for a book and show whether they can borrow it.

**Your program should use:** an array of book objects, a loop to search the books, and conditionals to check availability and show an appropriate message.

## 6. Healthy Snack Picker

Build a snack picker that recommends a snack based on a person's preferences, such as whether they want something sweet or savory and whether they have a food allergy. Show only snacks that match the person's choices and do not contain the allergen they entered.

**Your program should use:** an array of snack objects, a loop to check each snack, and conditionals to match preferences and exclude allergens.

## 7. Daily To-Do List

Build a program that stores a student's tasks for the day. Let the student mark tasks as complete, then show which tasks are finished and which still need to be done.

**Your program should use:** an array of task objects, a loop to display or check tasks, and conditionals to show different statuses.

## 8. Number Guessing Challenge

Build a game where the player tries to guess a secret number. After each guess, tell the player whether the guess is too high, too low, or correct. Keep track of how many guesses they used.

**Your program should use:** variables for the secret number and guess count, a loop to allow repeated guesses, and conditionals to compare each guess with the secret number.

## 9. Weather Outfit Advisor

Build a program that suggests what to wear based on the weather. The user can enter a temperature and whether it is raining or windy. Show a suitable outfit suggestion for the conditions.

**Your program should use:** an object to store weather information, variables for the user's input, and conditionals to choose suggestions. You could use an array and a loop to show several clothing items.

## 10. Sports Team Scoreboard

Build a program that keeps track of teams and their scores in a small tournament. Show each team's score, identify the team with the highest score, and announce a winner or a tie.

**Your program should use:** an array of team objects, a loop to compare scores, and conditionals to identify the highest score and decide whether there is a tie.
